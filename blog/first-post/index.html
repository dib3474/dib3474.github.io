프로젝트 자료와 개발 실습 기록을 한곳에 모으기 위해 Astrofy로 포트폴리오와 블로그를 만들었습니다.

Astrofy를 선택한 이유

Astrofy는 자기소개, 이력서, 프로젝트 목록, 블로그 화면을 기본으로 제공합니다. 글을 Markdown으로 관리할 수 있고, 최신 글은 홈에 자동으로 표시됩니다. 레이아웃은 템플릿의 Tailwind CSS와 daisyUI 구성을 활용했습니다.

GitHub Pages에 배포하기

Astro 설정의 site에 GitHub Pages 주소를 지정하고 npm run build로 정적 파일을 생성합니다. public/.nojekyll은 빌드 결과에 복사되어 GitHub Pages가 _astro/ 자산 폴더를 그대로 제공하도록 합니다. 이 사이트는 main 브랜치의 루트에서 빌드 결과물을 배포합니다.

이곳에 개발 학습 노트와 프로젝트 회고를 이어서 정리할 예정입니다.
